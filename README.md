# 🎬 BD Animée Pro

> Transforme une planche de BD + ton visage en film d'animation professionnel.

**Version :** 1.0
**Licence :** MIT
**Auteur :** [leurre08](https://github.com/leurre08)

---

## ✨ Fonctionnalités

- 🖼️ Analyse de planche BD : détection automatique des cases et dialogues
- 👤 Face swap cohérent : ton visage préservé sur toutes les cases
- 🎨 6 styles BD : franco-belge, réaliste, cartoon, manga, aquarelle, encre
- 🎬 Animation automatique : chaque case devient une vidéo (Ken Burns + bulles)
- 🎞️ Assemblage final : player intégré + export MP4
- 💾 Sauvegarde locale : historique des projets en IndexedDB
- 📱 PWA installable : ajoute l'app à ton écran d'accueil Android
- 🌐 Mode hors-ligne : l'interface fonctionne sans connexion

---

## 🚀 Installation

### Option 1 — GitHub Pages (recommandé)

1. Ouvre `https://leurre08.github.io/bd-animee-pro/`
2. Sur Android : Chrome → menu → **Ajouter à l'écran d'accueil**
3. L'app s'installe comme une vraie application

### Option 2 — Fichier local

1. Télécharge le repo (bouton vert **Code** → **Download ZIP**)
2. Décompresse le ZIP
3. Ouvre `index.html` dans ton navigateur

---

## 📋 Utilisation

1. Colle ta clé API Agnes ([platform.agnes-ai.com](https://platform.agnes-ai.com))
2. Charge 2 photos : ta planche BD + ton visage
3. Choisis un style : franco-belge, réaliste, cartoon, manga, etc.
4. Édite le script : les cases et dialogues sont pré-remplis
5. Clique sur "Générer la BD animée"
6. Attends (3 à 15 minutes selon le nombre de cases)
7. Regarde le film ou télécharge-le
